# Triangular Arbitrage Scanner (Учебный проект)

Учебный сканер треугольного арбитража на Python. Подключается к бирже Bybit через CCXT, проверяет несколько треугольников валютных пар и рассчитывает профит с учётом комиссий и спреда (bid/ask).

**Главный вывод проекта:** на ликвидных парах треугольный арбитраж почти всегда убыточен из-за комиссий (0.3% за цикл) и спреда. Сканер честно показывает это в цифрах.

## Что делает

- Загружает рынки Bybit через `ccxt`.
- Проверяет список треугольников (BTC/USDT + ETH/USDT + ETH/BTC и т.д.).
- Считает полный цикл: `USDT → BTC → ETH → USDT`.
- Учитывает комиссию `0.1%` на каждой из трёх сделок.
- Использует `ask` для покупки и `bid` для продажи (реальные цены исполнения).
- Пропускает пары, которых нет на бирже (например, DOGE/BTC).
- Выводит профит в USDT и процентах.

## Требования

- Python 3.9+
- Библиотека `ccxt`
